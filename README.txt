ENGLISH GARDEN — ВЕРСИЯ ДЛЯ GITHUB PAGES (БЕЗ PHP)

Файлы сайта должны лежать ПРЯМО в корне репозитория:
index.html
style.css
script.js

НЕ загружайте только ZIP-файл в репозиторий. Сначала распакуйте архив на компьютере,
затем загрузите эти три файла в GitHub через Add file → Upload files.

КАК ИСПРАВИТЬ ОШИБКУ 404
1. Откройте свой репозиторий на GitHub.
2. На главной странице репозитория проверьте, что index.html виден сразу в списке файлов,
   а не внутри дополнительной папки.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Source: Deploy from a branch.
5. Выберите Branch: main и Folder: /(root), затем нажмите Save.
6. Подождите 2–5 минут и обновите страницу Pages. Нажмите Visit site.
7. Открывайте URL, показанный в Settings → Pages. Для репозитория english-garden он обычно
   выглядит так: https://ВАШ-ЛОГИН.github.io/english-garden/
   Замените ВАШ-ЛОГИН на свой логин GitHub. Это пример формата, не готовая ссылка.

Если репозиторий называется ВАШ-ЛОГИН.github.io, адрес будет другим:
https://ВАШ-ЛОГИН.github.io/

ФУНКЦИИ
- HTML/CSS/JavaScript, адаптация для телефона и анимации.
- Мобильное меню и переходы по разделам.
- Отметки выполненных уроков и процент прогресса.
- Прогресс сохраняется в localStorage этого браузера.
- PHP и сервер не нужны.

Ограничение: отметки не синхронизируются между разными устройствами или браузерами.
